01

설계 전제와 판단

비서의 말투로 시작한다

숫자판이 아니라 문장이 먼저. 종목 블록의 최상단은 항상 “오늘 이 종목에서 벌어진 일” 한 줄. 시세·차트·컨센서스는 그 문장을 뒷받침하는 근거로 아래에 접혀 있습니다.

카드를 쓰지 않는다

종목 구분은 테두리 박스가 아니라 굵은 상단 규칙선 + 48px 여백으로. 그림자·라운드 박스 중첩은 전면 금지. 표면(surface)은 펼친 상세 안쪽에서만 한 겹 사용합니다.

호재/악재는 3중 표기

색 + 도형 아이콘 + 텍스트 라벨(“호재 신호”/“악재 신호”/“중립”)을 항상 함께. 색을 못 봐도 의미가 전달되고, 등락은 ▲▼ 기호와 부호를 병기합니다.

로컬 우선, 계정 없음

관심종목은 localStorage에 저장 → 첫 진입은 반드시 빈 상태. 그래서 온보딩 빈 상태가 이 제품의 첫인상이며, 가장 공들여 설계해야 하는 화면입니다.

03

컬러 토큰 (OKLCH)

브랜드 색조 H 165 (딥그린)를 뉴트럴에 C 0.008~0.018로 미세하게 섞어 “틴티드 뉴트럴”을 만듭니다. 순수 블랙·순수 화이트 미사용. 다크(Nocturne)가 기본이며, 라이트는 명도 반전이 아닌 별도 램프로 재설계 — 표면이 배경보다 밝아지고, 신호색은 채도를 낮추고 명도를 올립니다.

한국 관행상 상승=적색이지만 색약 사용자에게 적/녹 대립은 최악의 조합입니다. 확정안은 기호 + 저채도 틴트 — 방향은 ▲▼와 부호가 전달하고, 색은 채도를 낮춘 --pos(H26) / --neg(H250)로 거들기만 합니다. 채도가 높은 신호색(호재 ◆ / 악재 ▽)은 브리핑 배지에만 쓰고, 두 배지는 색 없이도 도형으로 구분됩니다.

05

빈 상태 · 로딩 · 예외

4가지 상태를 컴포넌트 레벨에서 명시적으로 정의합니다. 문구는 모두 행동 서술형.

A · 첫 진입 (종목 0개)
아직 지켜볼 종목이 없습니다

한 종목만 넣어도 오늘의 브리핑이 만들어집니다.

+ 삼성전자 + SK하이닉스

추천 칩은 “예시로 채워보기” 용도 — 언제든 지울 수 있음을 명시.

B · 로딩 (스켈레톤)

스피너 없음. 실제 레이아웃 형태의 스켈레톤 + 1.6s opacity 펄스(0.6→1). prefers-reduced-motion에서는 정적.

C · 데이터 없음 (종목은 있음)
오늘은 조용합니다

새 뉴스·공시가 없습니다. 마지막 소식은 3일 전이었어요.

지난 소식 보기

“무소식”도 정보다 — 블록을 숨기지 않고 조용함을 명시.

D · 불러오기 실패
◈확인 필요

시세를 못 받아왔습니다. 뉴스는 정상이라 아래는 그대로 볼 수 있습니다.

시세만 다시 받기 지금은 넘어가기

부분 실패는 부분만 표시. 화면 전체를 에러로 덮지 않음.

모션 원칙

· 전체 transform / opacity만 사용
· 상세 펼치기 200ms cubic-bezier(.32,.72,0,1)
· hover: 배경 3% 틴트 + 좌측 규칙선 굵기 변화, 이동 없음
· focus-visible: 2px 브랜드 아웃라인 + 2px offset
· 숫자 갱신은 100ms 밝기 플래시 1회 (깜빡임 반복 금지)

07

확정된 결정

브랜드 색조 H 165 딥그린

상승 적색 / 하락 청색 관행과 색조가 겹치지 않는 유일한 축. 뉴트럴에도 C 0.009~0.015로 섞어 틴티드 뉴트럴을 만듭니다.

다크(Nocturne) 기본

기본값이 다크, 라이트는 별도 램프. 표면이 배경보다 밝아지고 텍스트는 순백을 쓰지 않습니다.

등락은 기호 + 저채도 틴트

▲▼와 부호로 방향을 표시하고, 색은 채도를 낮춘 --pos / --neg만. 강한 신호색은 호재/악재 배지에만 씁니다.

제목·브리핑에 명조

Gowun Batang. 데이터·라벨·차트는 IBM Plex Sans KR로 통일하고 숫자는 tabular-nums.

피드 + 사이드 레일

≥1024px 2열. ≤1023px에서는 레일이 피드 아래로 내려가고, 상단에는 44px 신호 요약 칩만 남습니다.

전부 무료 · 결제 없음

프리미엄·구독·결제 UI 없음. 적중률과 추정가도 전원 공개. 수익 요소는 “커피 한 잔” 후원 탭 하나이며 후원 특전은 만들지 않습니다.

09

추정가 · 괴리 표기 규칙

추정가는 지수 프록시라 신뢰 한계를 UI가 먼저 말해야 합니다. 네 가지를 항상 함께 노출합니다.

참고용 추정가 괴리 정보 ◈정확도 낮음 환율 보정 반영
· 라인 구분은 색 + 선 스타일 — 실제가 실선 / 추정가 파선
· 괴리 확대 강조는 색이 아니라 테두리 2px + 숫자 굵기
· 괴리는 매수·매도 신호가 아니라는 문구를 스트립 바로 아래 고정
· 갱신 시각을 분 단위로 노출 — “근접 실시간(약 15분 지연)”, “완전 실시간” 표현 금지
· 중소형주는 위젯 비노출 또는 ◈ 정확도 낮음
10

구현 메모

차트 — TradingView Lightweight Charts

Vue 앱에서는 tradingview-proxy-chart.js의 createProxyChart()를 그대로 사용합니다. 함정 두 가지:

· 시리즈·축 색상에 oklch()를 넘기면 파싱 실패로 선이 그려지지 않습니다 → 차트에 넘길 값만 rgb()
· 컨테이너 높이와 chart 높이를 일치시키고 ResizeObserver에서 resize() 호출
· 시안 파일은 미리보기 환경 제약으로 동일 데이터의 SVG 차트를 씁니다

모바일 · PWA

· 세이프에어리어 상단 56px / 하단 32px
· 하단 3탭: 브리핑 · 추정가 · 커피 한 잔
· “홈 화면에 추가” 안내는 1회 노출 + “지금은 넘어가기”
· 오프라인은 마지막 브리핑 화면만 캐시
· 모든 터치 타깃 44px 이상
